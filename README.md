# ProtoLab · Circuito lógico

Vista visual del montaje real de Oliver Robles, protoboard interactivo y seis compuertas lógicas.

Entradas A, B y C mediante DIP. Secuencia de salida para 000–111: 1, 0, 1, 0, 1, 0, 1, 1.

Sitio estático sin dependencias de compilación. Archivos de publicación en `dist/`.
